# Breast Cancer Classification (Wisconsin Diagnostic)

Binary classification of breast masses as benign or malignant from 30 tabular features, with emphasis on
**leakage-free evaluation, threshold choice for a screening setting, and honest false-negative analysis**.

> **Disclaimer:** educational project. It is not a clinically validated diagnostic system and must not be used for medical decisions.

## Project structure
```
data/        dataset documentation (+ optional CSV export)
notebooks/   01 EDA, 02 training, 03 evaluation (executed, outputs included)
src/         data_loader, preprocessing, train, evaluate, explain
models/      saved pipeline + metadata (generated by training)
reports/     model_comparison.csv, false_negatives.csv, permutation_importance.csv, figures/
app.py       optional Streamlit demo
```

## Quick start
```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m src.train        # trains 3 models, saves best to models/, writes reports/model_comparison.csv
python -m src.evaluate     # test-set report, confusion matrices, ROC, calibration, false negatives
python -m src.explain      # permutation importance
streamlit run app.py       # optional demo
```
Run all commands from the repository root.

## Methodology
- **Split:** stratified 80/20 (455 train / 114 test), fixed seed 42. The test set is used once for final numbers.
- **Preprocessing:** `StandardScaler` inside a scikit-learn `Pipeline`, so scaling is fit on training folds only.
- **Models:** Logistic Regression, Random Forest, Gradient Boosting (class weights where supported).
- **Selection:** 5-fold CV PR-AUC on the training set. The test set plays no part in choosing the model.
- **Threshold:** highest threshold reaching 98% recall on out-of-fold *training* predictions, compared with the default 0.5.
- **Metrics:** PR-AUC and ROC-AUC, recall, precision, raw FN/FP counts, Brier score and a calibration curve.

## Results (test set: 114 samples, 42 malignant)
Measured values from `reports/model_comparison.csv`:

| Model | CV PR-AUC | Test PR-AUC | Test ROC-AUC | FN / FP @0.5 | FN / FP @tuned |
|---|---|---|---|---|---|
| **Logistic Regression** (selected) | 0.994 | 0.993 | 0.995 | 2 / 1 | 2 / 2 |
| Random Forest | 0.988 | 0.995 | 0.997 | 4 / 0 | 1 / 4 |
| Gradient Boosting | 0.989 | 0.992 | 0.995 | 4 / 0 | 3 / 2 |

Selected model at 0.5: recall 0.952, precision 0.976, Brier score 0.022.

**What this shows**
- All three models are essentially tied. Differences amount to 1-2 test cases, well inside noise.
- Threshold tuning helped Random Forest (4 to 1 missed cancers, at the cost of 4 false alarms) but did **not** reduce false negatives for the selected Logistic Regression on this split.
- The 2 missed malignant cases at 0.5 (samples 73 and 190) had unusual profiles, e.g. atypical texture or error terms (`reports/false_negatives.csv`).
- Top permutation-importance features are `worst texture`, `worst symmetry` and `worst concavity`. Many features are strongly correlated (15 pairs with |r| > 0.95), so importance is split between them and individual rankings are unreliable.

## Limitations
- **Small data:** 42 malignant test cases means one error shifts recall by ~2.4 points. Single split; no confidence intervals on test metrics.
- **No external validation:** one dataset from one source. Performance on other sites, scanners or populations is unknown.
- **Easy benchmark:** AUC near 0.99 reflects a clean, well-separated dataset, not a solved clinical problem.
- **Tabular, not images:** features were pre-extracted; this does not test image analysis.
- **Missed cancers remain:** even the best configuration misses cases, so the model cannot rule out disease.
- **No subgroup/fairness analysis** (age, density, etc.) because those attributes are unavailable.

## Possible extensions
Bootstrap confidence intervals, repeated nested CV, probability calibration (isotonic/Platt), SHAP, and an image-based
counterpart (e.g. a CNN on BreakHis or PathMNIST) to complete a full medical-imaging project.

## Reproducibility
Seed 42 throughout. Results were generated with scikit-learn 1.x; small numeric differences across versions are possible.
